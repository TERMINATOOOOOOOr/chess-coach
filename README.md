# Shoh — шахматный тренер с ИИ

Играешь с ботом, а рядом сидит тренер на движке Stockfish: подсказывает ход, предупреждает
об угрозах и объясняет ошибки по-русски. Всё работает в браузере и офлайн, ключи и сервер не нужны.

## Запуск

- **Проще всего:** открыть `dist/shoh.html` двойным кликом. Это один файл, движок встроен.
- **Для разработки:** `python -m http.server 8765`, затем открыть http://127.0.0.1:8765/
  (модули и Web Worker не грузятся по `file://`, поэтому нужен сервер).

## Что умеет тренер

| Функция | Как работает |
|---|---|
| Подсказка в 3 шага | 1 — идея («есть вилка», «соперник грозит матом»), 2 — подсветка фигуры, 3 — стрелка и объяснение хода |
| Лучшие ходы | Топ-3 линии движка: стрелки, оценка и короткая причина каждого хода |
| Угрозы | «Нулевой ход»: что сыграл бы соперник, если бы ход был его. Красная стрелка и предупреждение |
| Оценка каждого хода | Сильная жертва / Лучший / Отличный / Хороший / Неточность / Ошибка / Зевок по падению шанса на победу (2 / 5 / 10 / 20 %) |
| Объяснение ошибок | «Соперник отвечает Фxg5 и выигрывает коня. Лучше было Сb5: развивает фигуру» |
| Взять назад | После ошибки можно вернуть ход и попробовать снова |
| Итог партии | Точность в %, сколько лучших ходов, ошибок и зевков |
| Ошибки бота | Если бот ошибся, тренер подскажет, что его можно наказать |

Объяснения не генерирует языковая модель: они собираются по шаблонам из анализа Stockfish и разбора
позиции через chess.js (взятия, вилки, висящие фигуры, защита от мата, выигрыш материала по линии
движка). Поэтому тренер не выдумывает варианты, но формулировки у него проще, чем у живого тренера.

## Боты

Шесть уровней: Пешка ≈400, Конь ≈800, Слон ≈1200, Ладья ≈1600, Ферзь ≈2000, Король ≈2200 (Elo
примерный). Stockfish даже на минимальном Skill слишком силён для новичка, поэтому слабые боты
«очеловечены»: выбирают из нескольких линий со случайным весом, иногда зевают и делают случайные ходы.

Тренер всегда считает глубже любого бота: в позиции игрока до глубины 16 и до 2.5 с, а Король
ограничен глубиной 12 и 0.8 с. Поэтому игра строго по «лучшим ходам» выигрывает у каждого бота.

## Устройство

```
index.html          разметка: доска, панель тренера, окна выбора соперника и итога
css/app.css         тема и вёрстка (адаптив до 360 px, prefers-reduced-motion)
js/engine.js        UCI-обёртка над Stockfish в Web Worker: очередь, MultiPV, отмена
js/coach.js         классификация ходов, угрозы, подсказки, тексты (чистые функции)
js/bots.js          уровни ботов и выбор хода
js/board.js         доска: drag & drop и клики, анимация, стрелки, превращение
js/app.js           ход партии и связка всего вместе
vendor/             stockfish.js 10.0.2 (asm.js), chess.js 1.0.0
assets/pieces.css   фигуры cburnett
tools/bundle.py     сборка dist/shoh.html
```

Работают два воркера Stockfish: один думает за бота, второй анализирует для тренера
(MultiPV 3, Contempt 0). Поэтому подсказки не ждут хода бота. Движок получает позицию как
«стартовый FEN + все ходы партии», поэтому видит повторения и не отдаёт ничью в выигранной позиции.

## Тесты

```
node --test tests/*.test.mjs          # логика тренера + интеграция с настоящим Stockfish (~5 с)
python tests/e2e.py                   # браузер (Playwright): партия, подсказки, зевок, угроза, мат, телефон
python tests/e2e.py --file dist/shoh.html   # то же для однофайловой сборки по file://
python tools/bundle.py                # пересобрать dist/shoh.html
```

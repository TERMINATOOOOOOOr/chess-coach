# Shoh — шахматный тренер с ИИ

Тренер на движке Stockfish, на телефоне и на компьютере.

- **Играть.** Партия с ботом, а тренер подсказывает ход, предупреждает об угрозах и объясняет
  ошибки по-русски.
- **Партии.** Тренер сам подтягивает твои законченные партии с chess.com и разбирает их: где
  ошибся, что было лучше, ключевые моменты. Из любого момента можно доиграть позицию с ботом.
- **Прогресс.** Точность по партиям, в какой фазе теряешь больше всего и какие ошибки чаще.

Всё считается на устройстве. Сервера и ключей нет, партии хранятся только на телефоне.

## Установка на телефон

- **Сайт-приложение:** https://terminatooooooor.github.io/chess-coach/. В Chrome на Android:
  меню ⋮ → «Добавить на гл. экран». После этого в приложении chess.com работает
  «Поделиться» → Shoh.
- **APK:** https://github.com/TERMINATOOOOOOOr/chess-coach/releases/latest/download/shoh.apk.
  Скачать, открыть и разрешить установку из этого источника.

## Обновления

- **APK обновляется сам** (`js/updater.js`). При запуске тихо сверяется с `version.json` на
  GitHub Pages и скачивает только изменившиеся файлы, каждый проверяя по sha256. Новая версия
  включается при следующем запуске. Если она не дошла до успешного старта, приложение вернётся к
  прежней, а после двух неудач пометит её плохой. Партии и настройки сохраняются.
- Новый APK нужен, только если обновлению требуется новый нативный плагин (поле `requires` в
  `version.json`). Тогда в «Настройках» появится «Скачать APK». Сборка APK запускается только при
  изменении нативной части (`android/`, `capacitor.config.json`, `package*.json`).
- Сайт-приложение обновляется через service worker.

## Честная игра

Разбираются только **законченные** партии из открытого архива chess.com
(`api.chess.com/pub/player/<ник>/games/<год>/<месяц>`). Подсказок во время игры на chess.com нет и
не будет: это нарушило бы правила fair play.

## Что умеет тренер в игре с ботом

| Функция | Как работает |
|---|---|
| Подсказка в 3 шага | 1 — идея («есть вилка», «соперник грозит матом»), 2 — подсветка фигуры, 3 — стрелка и объяснение хода |
| Лучшие ходы | Топ-3 линии движка: стрелки, оценка и короткая причина каждого хода |
| Угрозы | «Нулевой ход»: что сыграл бы соперник, если бы ход был его. Красная стрелка и предупреждение |
| Оценка каждого хода | Сильная жертва / Лучший / Отличный / Хороший / Неточность / Ошибка / Зевок по падению шанса на победу (2 / 5 / 10 / 20 %) |
| Объяснение ошибок | «Соперник отвечает Фxg5 и выигрывает коня. Лучше было Сb5: развивает фигуру» |
| Взять назад | После ошибки можно вернуть ход и попробовать снова |
| Ошибки бота | Если бот ошибся, тренер подскажет, что его можно наказать |

Объяснения не генерирует языковая модель: они собираются по шаблонам из анализа Stockfish и разбора
позиции через chess.js (взятия, вилки, висящие фигуры, защита от мата, выигрыш материала по линии
движка). Поэтому тренер не выдумывает варианты, но формулировки у него проще, чем у живого тренера.

## Разбор партий

- По одному анализу движка на позицию. Анализ позиции i служит оценкой «до» для хода i и «после»
  для хода i−1.
- Если сыгранного хода нет среди лучших линий, он считается отдельно из той же позиции и на ту же
  глубину (`searchmoves`). Иначе шум мелкого поиска выглядел бы как ошибки.
- В первых 8 ходах падение оценки смягчается (×0.6): на малой глубине Stockfish 10 сильнее всего
  «шумит» в дебюте. Настоящие зевки остаются зевками.
- Типы ошибок для «Прогресса»: допустил мат, упустил мат, зевнул материал, упустил тактику,
  позиционная ошибка.
- Режимы: «точно» (глубина 12, до 2 с на позицию) и «быстро» (10, до 0.9 с). На телефоне партия на
  40 ходов разбирается за 1–3 минуты в фоне. Пока идёт партия с ботом, разбор на паузе.

## Боты

Шесть уровней: Пешка ≈400, Конь ≈800, Слон ≈1200, Ладья ≈1600, Ферзь ≈2000, Король ≈2200 (Elo
примерный). Слабые боты «очеловечены»: выбирают из нескольких линий со случайным весом, иногда
зевают. Тренер всегда считает глубже любого бота, поэтому игра по «лучшим ходам» выигрывает у каждого.

```
index.html            разметка всех экранов

```

## Разработка и тесты

```
python -m http.server 8765            # открыть http://127.0.0.1:8765/
node --test tests/*.test.mjs          # логика, chess.com (фикстура), разбор на настоящем Stockfish
python tests/e2e.py                   # браузер: игра, подсказки, телефонное приложение, офлайн
python tests/e2e.py --file dist/shoh.html
python tools/build_site.py && python tests/e2e_updater.py   # живые обновления APK в имитации Capacitor
python tools/bundle.py                # пересобрать dist/shoh.html
```

APK собирается в GitHub Actions. Ключ подписи лежит в секретах репозитория
(`SHOH_KEYSTORE_B64`, `SHOH_KEYSTORE_PASSWORD`), его резервная копия хранится вне репозитория.
Без этого ключа новые версии не встанут поверх уже установленной.
